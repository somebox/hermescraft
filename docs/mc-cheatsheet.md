# mc command cheatsheet

One line per command. Use `mc <command> --help` for full detail (args, types, examples).

Generated by `scripts/gen-mc-cheatsheet.mjs` from `bot/cli/registry.mjs`. Do not edit by hand.

## observe

- `mc alerts` — Typed alerts
- `mc anchors` — Known anchor marks
- `mc connect` (reconnect) — Reconnect bot to server
- `mc craft_plan ITEM [COUNT]` (cp) — Dependency check crafting plan
- `mc deaths` — Recent death events
- `mc discover CATEGORY [RADIUS]` (disc) — Scan for category (logs/wood/food/etc)
- `mc fair_play [ENABLED]` — Toggle reaction-delay preamble (fair-play vs instant)
- `mc furnaces` — List known furnace marks + smelt status
- `mc health` (h) — HP/food/effects summary
- `mc inventory` (inv, i) — List items in bot inventory
- `mc logistics` (log) — Logistics rollup
- `mc look` (survey) — What the bot is currently facing
- `mc map [RADIUS]` (m) — Compact ASCII map of nearby terrain
- `mc nearby [RADIUS]` (n) — List nearby blocks/entities within radius
- `mc observe` (snapshot) — Goals + task + alerts snapshot
- `mc scene [RANGE]` (perceive, vision) — Visible entities + landmarks in vision range
- `mc screenshot_meta` (ss_meta) — Reserved for paired screenshot + state for vision; handled in CLI only until wired to HTTP.
- `mc sounds` — Recent footstep / mob sounds
- `mc stats` — Bot session stats (uptime, errors, etc.)
- `mc status` (state, s) — Full game snapshot

## movement

- `mc deathpoint` — Walk to most recent death location
- `mc follow PLAYER` (f) — Follow a player by name
- `mc goto X Y Z` (go, g) — Walk to absolute block coordinates
- `mc goto_near X Y Z [RANGE]` (near) — Walk to within RANGE blocks of target
- `mc look_at X Y Z` — Turn the bot to face X Y Z
- `mc stop` — Cancel current movement task

## world

- `mc build_stairs BLOCK DIR LEN [X Y Z]` — Build an ascending triangular ramp of BLOCK in cardinal DIR for LEN steps. Each column i is filled from the floor up to height i, so column 1 is 1 block tall, column 2 is 2 blocks, etc. The bot walks up the ramp as it builds. Total blocks = LEN*(LEN+1)/2; LEN is capped at 16.
- `mc chest X Y Z  OR  mc chest @MARK` (list_container) — Open + list a chest at X Y Z or @MARK
- `mc chest_search ITEM [MAX_RESULTS]` (cs, find_in_chests) — Search known chest snapshots (cached from prior list/deposit/withdraw) for an item across all marks. No chest is opened — returns marks + counts. Workers should use this BEFORE deciding which chest to walk to.
- `mc close` — Close currently-open container
- `mc collect BLOCK [COUNT]` (mine, c) — Find + mine N of a block type within radius
- `mc deposit ITEM COUNT X Y Z  OR  mc deposit ITEM COUNT MARK  OR  mc deposit ITEM @MARK` — Deposit items into a chest (count=0 means all).
- `mc dig X Y Z` (d) — Break the block at X Y Z (single block)
- `mc dig_area X1 Y1 Z1 X2 Y2 Z2` (da, clear_area) — Mine diggable blocks in an axis-aligned box (high Y first; optional stand-block nudge per layer). Max 500 blocks.
- `mc dig_pit X Z W L D [TOP_Y]` — Dig a W×L×D pit at corner (X, Z). Top of pit defaults to bot Y - 1 (the surface block); pit floor ends up at top - D. Use mc build_stairs separately to add stairs out. Max 256 columns × 16 depth.
- `mc equip ITEM [SLOT]` (eq) — Equip ITEM to hand or armor SLOT
- `mc feed_mob TARGET [ITEM]  OR  mc feed_mob TARGET --item ITEM` (feed, use_on_mob) — Right-click mob with held item (breeding food, bucket on cow, etc.)
- `mc fence BLOCK X1 Z1 X2 Z2 [--gate DIR] [--y Y]` — Build a fence enclosure (rectangle perimeter at one Y) of BLOCK between two corners. Optional --gate DIR (north|south|east|west) places a matching fence_gate at the midpoint of that side. Min 3×3.
- `mc fill BLOCK X1 Y1 Z1 X2 Y2 Z2 [HOLLOW]` — Fill an axis-aligned box with BLOCK
- `mc find_blocks BLOCK [RADIUS] [COUNT]` (find, fb) — Locate blocks of TYPE within radius (no mining)
- `mc find_entities [TYPE] [RADIUS]` (fe) — Locate entities of TYPE within radius
- `mc interact X Y Z` (use_block) — Right-click block at X Y Z (door/lever/button)
- `mc level X1 Z1 X2 Z2 Y [BLOCK] [UP]` — Flatten a rectangle to target Y: dig solid blocks above Y (up to 8 by default), and fill any air gaps at Y with a leveling block. Auto-picks a fill block from {dirt, cobblestone, stone} unless BLOCK is given. Below Y is not touched. Max 256 columns.
- `mc path X1 Z1 X2 Z2 [Y]` — Convert dirt/grass/podzol/coarse_dirt/mycelium/rooted_dirt to dirt_path inside an axis-aligned rectangle, using a shovel. Default Y is bot Y-1 (the floor). Skips columns that are already path, non-dirt, or covered by a non-air block above.
- `mc pickup` (p) — Walk to + collect a nearby item drop
- `mc pillar_step [BLOCK] [COUNT] [JUMP]` (tower, pillar) — Climb upward by placing blocks underfoot. Use count to climb multiple blocks in one call (max 64).
- `mc place BLOCK X Y Z` (pl) — Place a block at X Y Z (block from hand)
- `mc respawn yes` — Kill and respawn at spawn point. Use when hopelessly stuck underground with no tools or resources to escape. All inventory is dropped at the death location.
- `mc set_home [X Y Z]` (sethome) — Set your respawn point. Uses server command if available, otherwise finds a bed to sleep in. Call this at your base before going deep underground.
- `mc sleep` (bed) — Find a nearby bed (up to 32 blocks), navigate to it, and sleep. Sets your spawn point.
- `mc stair_down DIR [LENGTH] [X Y Z] [WIDTH] [HEIGHT]` (mine_stairs, stairs_down) — Dig a descending staircase (one down per forward step) for reliable mine routes.
- `mc stair_up DIR [LENGTH] [X Y Z] [WIDTH] [HEIGHT]` (stairs_up, escape) — Dig an ascending staircase (one up per forward step). Places floor blocks over voids. Use to escape deep caves safely.
- `mc terrain_top X Z [RADIUS]` (ttop, surface_y) — Top solid block in column(s): highest non-air, non-fluid from sky down (optional square radius).
- `mc through GX GY GZ [DX DY DZ]` — Pass through a fence_gate, door, or trapdoor: opens it, walks to the far side, closes it behind. Destination defaults to 2 blocks past the gate on the opposite side from the bot.
- `mc toss ITEM [COUNT]` (drop) — Drop ITEM [COUNT] from inventory
- `mc tunnel X Y Z DIR LENGTH [WIDTH] [HEIGHT]` (mine_tunnel) — Dig a straight tunnel using repeated dig_area slices (industrial corridor primitive).
- `mc unequip [SLOT]` (uneq) — Clear main hand (or slot). Use before chopping logs without an axe.
- `mc use` (u) — Activate held item (right-click in air)
- `mc wait [SECONDS]` (w) — Pause N seconds (no-op until timeout)
- `mc wall BLOCK X1 Y1 Z1 X2 Y2 Z2` — Build a wall (vertical line/rect) of BLOCK between two corners. y1 must differ from y2.
- `mc withdraw ITEM COUNT X Y Z  OR  mc withdraw ITEM COUNT MARK  OR  mc withdraw ITEM @MARK` — Withdraw items from a chest (count=0 means all).

## craft

- `mc craft ITEM [COUNT]` (cr) — Craft ITEM [COUNT] using inventory + nearby crafting table
- `mc furnace_check X Y Z` (fc) — Status of a specific furnace (input/output/fuel)
- `mc furnace_take X Y Z` (ft) — Withdraw smelted output from furnace
- `mc recipes ITEM` (recipe, r) — List craftable items given current inventory
- `mc smelt INPUT [FUEL] [COUNT]   # synchronous; blocks ~12s per item` (sm) — Smelt INPUT [COUNT] in nearby furnace (foreground)
- `mc smelt_start INPUT [FUEL] [COUNT]` (sstart) — Begin background smelt task (returns task id)

## combat

- `mc attack [TARGET]` (kill, a) — Single attack on TARGET (one swing)
- `mc combat_skill [VALUE]` (skill) — Per-agent combat skill 0..1 (soldier≈0.9, default 0.5, farmer≈0.2). No arg = report current.
- `mc combo` — Pre-defined attack sequence on TARGET
- `mc crit [TARGET]` (critical) — Jump-attack TARGET for critical-hit damage
- `mc eat` (e) — Eat the best food in inventory
- `mc fight [TARGET] [RETREAT_HEALTH] [DURATION]` — Fight loop on TARGET until dead or HP threshold
- `mc flee [DISTANCE] [--to MARK]` — Flee distance (number) or flee --to mark. Plan: mc flee --to @home (supports --to; legacy: mc flee 16)
- `mc mode [NAME]` — Set reactive mode: normal | guard | hold. No arg = report current mode.
- `mc shield [DURATION]` (block) — Raise shield (block) for SECONDS
- `mc shoot [TARGET] [PREDICT]` (bow) — Fire bow at TARGET (must hold bow + arrows)
- `mc sneak [ENABLE]` — Toggle sneak (crouch)
- `mc sprint_attack [TARGET]` (sa) — Sprint into TARGET for knockback hit
- `mc strafe` — Sidestep TARGET while attacking

## memory

- `mc go_mark NAME` — Walk to a saved mark
- `mc mark NAME [NOTE]` — Save current position as named mark
- `mc mark_update` (mark-up, mu) — Move existing MARK to current position
- `mc marks` — List all marks
- `mc unmark NAME` — Delete a mark by name

## goals

- `mc goal_add` — Add a new goal (id + metric + thresholds)
- `mc goal_load PRESET` (load_goals) — Load a goal preset (miner/builder/etc.)
- `mc goal_presets` — List built-in goal presets
- `mc goal_remove` (goal_rm) — Remove goal by id
- `mc goal_set` — Set goal field (priority, target, etc.)
- `mc goal_status` (gs) — Detail status of a single goal
- `mc goals` — List active goals with urgency

## task

- `mc bg` (bg_any) — POST /task/ACTION — first arg action name; rest merged JSON.
- `mc bg_collect BLOCK [COUNT]` — Background mine N of BLOCK
- `mc bg_combo` — Background combo attack sequence
- `mc bg_fight [TARGET] [RETREAT_HEALTH] [DURATION]` — Background fight loop
- `mc bg_goto X Y Z` — Background walk to X Y Z
- `mc bg_smelt INPUT [FUEL] [COUNT]   # background; returns task_id, poll mc task` (bsm) — Background smelt batch
- `mc bg_strafe` — Background strafe loop
- `mc cancel` — Cancel current task
- `mc checkpoint` (chk) — Set agent decision checkpoint
- `mc checkpoint_respond` (cpr) — Respond to a pending checkpoint
- `mc remind` — Set a periodic reminder (surfaced in mc observe)
- `mc reminders` (list_reminders) — List all active reminders
- `mc task` (task_status) — Status of background task by id
- `mc task_history` (tasks_done) — List recent task runs
- `mc task_pause` — Pause running task
- `mc task_resume [LEASE_SECONDS]` — Resume paused task
- `mc task_start` (tstart) — Start named background task with args
- `mc unremind` (rm_remind) — Remove a reminder by id

## social

- `mc acknowledge_command [INDEX] [PLAN]` (ack) — Acknowledge receipt of a queued command
- `mc cancel_command [INDEX] [REASON]` (reject) — Cancel a pending queued command
- `mc chat MESSAGE` (say) — Public chat message
- `mc chat_to PLAYER MESSAGE` — Direct chat to PLAYER
- `mc cmds` (queue, command_queue) — Pending slash-command queue from chat (HermesCraft). Prefer `mc commands` (plan) for CLI registry.
- `mc complete_command [INDEX] [MESSAGE]` (done) — Mark a queued command as complete
- `mc overhear [COUNT]` (overheard, eavesdrop) — Recent chat from other bots/players (filtered)
- `mc rally` — Move all team bots to current position
- `mc read_chat [COUNT]` (messages, msg) — Recent public chat messages
- `mc report MESSAGE` — Submit a status report (event-based)
- `mc set_team` — Join named team channel
- `mc social` — Social state: nearby players + interactions
- `mc team_chat MESSAGE` (tc) — Chat to current team channel
- `mc team_status` (ts) — Current team membership + roster
- `mc whisper PLAYER MESSAGE` (dm, tell, private) — Whisper (private) to PLAYER

## platform

- `mc batch` — Run multiple mc calls in one invocation
- `mc commands` — Dump CLI registry metadata as JSON.
- `mc dashboard` (dash) — Open the bot dashboard URL
- `mc help` — Human-readable grouped help.
