# 3 Academic Papers: LLM Agents in Simulated Worlds

## 1. MineDreamer: Learning to Follow Instructions via Chain-of-Imagination for Simulated-World Control

- **Authors:** Enshen Zhou, Yiran Qin, Zhenfei Yin, Yuzhou Huang, Ruimao Zhang, Lu Sheng, Yu Qiao, Jing Shao
- **Year:** 2024
- **URL:** https://arxiv.org/abs/2403.12037
- **Takeaway:** Introduces MineDreamer, an embodied LLM agent in Minecraft that generates a "chain of imagination" (visual sub-goal plans) before acting, enabling the agent to follow complex sequential instructions much more reliably by first imagining what intermediate states look like.

## 2. CausalMACE: Causality Empowered Multi-Agents in Minecraft Cooperative Tasks

- **Authors:** Qi Chai, Zhang Zheng, Junlong Ren, Deheng Ye, Zichuan Lin, Hao Wang
- **Year:** 2025
- **URL:** https://arxiv.org/abs/2508.18797
- **Takeaway:** Proposes a multi-agent LLM system for Minecraft where agents use causal reasoning to decompose cooperative tasks into sub-tasks and coordinate efficiently, addressing the limitations of single-agent approaches on long-horizon collaborative tasks.

## 3. Experience Transfer for Multimodal LLM Agents in Minecraft Game

- **Authors:** Chenghao Li, Jun Liu, Songbo Zhang, Huadong Jian, Hao Ni, Lik-Hang Lee, Sung-Ho Bae, Guoqing Wang, Yang Yang, Chaoning Zhang
- **Year:** 2026
- **URL:** https://arxiv.org/abs/2604.05533
- **Takeaway:** Proposes Echo, a transfer-oriented memory framework for multimodal LLM agents in Minecraft that decomposes past experiences into five reusable dimensions (structure, attribute, process, function, interaction), achieving 1.3x-1.7x speed-ups on new tasks by learning what knowledge transfers across different in-game tasks.
