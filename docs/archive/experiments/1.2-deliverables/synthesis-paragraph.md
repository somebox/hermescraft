# LLM-Driven Game AI: State of the Art

The landscape of LLM-driven game AI splits across three dimensions: how agents represent actions, how they plan, and how they remember. **Generative Agents** and **Voyager** represent the complete-system frontier — the former using natural-language actions with a reflective planning hierarchy and three-tier episodic memory, the latter generating executable JavaScript skills via GPT-4 with curriculum-driven self-improvement and a vector-stored skill library. Both ship real, playable agents. Meanwhile, the research literature is pushing beyond these architectures: **MineDreamer** introduces Chain-of-Imagination, a visual sub-goal planning mechanism that bridges language instructions to low-level motor control — something no current project implements. **CausalMACE** tackles the underexplored problem of multi-agent coordination by having agents share causal knowledge graphs to reason about task dependencies jointly. **Echo** proposes the most sophisticated memory system across all six works — a five-dimensional experience decomposition (structure, attribute, process, function, interaction) that enables cross-task transfer and 1.3x–1.7x speed-ups — but lacks a public code release. **GamingAgent** fills a complementary gap as a cross-genre evaluation framework for LLM/VLM game-playing, compensating for the near-exclusive focus on Minecraft in both papers and projects. The core pattern is clear: projects prioritize end-to-end systems in single domains, while papers explore mechanisms — visual planning, causal coordination, transferable memory — that could meaningfully augment those systems in the next generation of game AI.
