## Recommendations for Phase 9

1. **Prioritize task #42 (goto_near 8s wallclock cap).** Gatherer's run-5 ends with the cap as the only top_error and accounts for ≥6 cycles of derail. Phase-8.B's "within 2" leniency hits the same upstream timeout — extending the cap to **15 s** (and surfacing time-spent on a NAV_BLOCKED return) likely converts several "pathfinder gave up" failures into successes without code changes elsewhere.
2. **Verb-cap awareness in Gatherer SOUL.** Add an explicit rule: "If `collect N` returns wallclock-exceeded, retry with `N ≤ 16` from the same spot before moving on." Run-5 had **7 collect:error vs 5 collect:done** — half of which were the 40s cap that a smaller batch size would have skipped (issue #55 / #51 docs gap also applies).
3. **Cap Pattern-E whispers at the orchestrator.** Steward's two pillar-up-to-absolute-Y orders to Gatherer in run-5 (05:18, 06:09) directly produced one residual cobble pillar (Y=85→Y=105) and consumed ~20 iterations of the budget. Add a Steward pre-send filter: if a whisper contains `pillar_up <N>` with N>5 or includes a literal absolute Y, replace with `mc escape` / `mc surface` advice or block the send.
